# Island Kingdom

A small kingdom-management game that runs in the browser and works offline.

Play it at https://bcrob4.github.io/Kingdom/ — on a phone, use the browser menu's **Install app** or **Add to home screen**.

The game is a single file, `index.html`. The master copy lives in Google Drive (`Documents/Kingdom/kingdom-offline.html`); `publish.sh` copies it here and pushes it.
